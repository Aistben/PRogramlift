# Тренировочный проект

Репозиторий ведения силовой подготовки: профиль спортсмена, действующая
программа, журнал фактических тренировок и материалы следующего цикла.

Актуально на 26 сентября 2026.

## Как пользоваться

### Обработка отчёта о тренировке

Полный порядок — раздел 9 профиля. Кратко:

1. Прочитать профиль, программу и последние записи журнала.
2. Изложить, как понят отчёт, и перечислить неоднозначности.
3. Дождаться подтверждения, только после него считать данные фактом.
4. Сравнить факт с назначением, объяснить причину каждого изменения.
5. Обновить журнал и HTML-программу: чипы «было → сейчас» заполняются
   фактом прошедшей недели и назначением на следующую.

### Изменение упражнения

Сначала прочитать его историю в журнале целиком — по оглавлению. Коридор
повторов назначается отдельно под каждое упражнение, а не общим шаблоном.

### Построение нового цикла

1. `05_Правила_программы.md`, раздел «Что переносится в будущие циклы».
2. `03_Анализ_программы.md` — итоги предыдущего цикла.
3. Журнал — факты и выявленные слабые места.
4. Профиль, раздел «Оформление HTML-программ» — требования к вёрстке.

### Правило истории

Подтверждённые факты не переписываются задним числом. Если значение изменилось,
прежнее остаётся и помечается как действовавшее на тот момент.
