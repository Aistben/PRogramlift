## Правила ведения

1. **Номер файла = порядок чтения внутри папки**, а не дата создания.
2. **Завершился цикл** — его папка переезжает в `Архив/` под именем `Цикл_<буква>_<год>`,
   итоги переносятся в `03_Итоги_циклов.md`.
3. **Ничего не удаляем.** Отменённые решения помечаются датой отмены, но остаются.
4. **Ссылки между файлами — относительными путями**, чтобы работали и на GitHub, и локально.
